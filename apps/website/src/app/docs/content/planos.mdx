## Visão geral

### RadRes+

- Exclusivo para residentes verificados
- 350 laudos por mês
- 7 dias grátis

### PRO

- Até 2.000 laudos por mês
- IA assistiva para edição, complementação e suporte clínico
- Fluxo completo de laudo no editor

### Enterprise

- Laudos ilimitados
- CRIT com SLA e auditoria
- Integrações PACS/RIS
- SSO / SAML e suporte dedicado

## Como escolher

- **RadRes+** para formação e uso inicial
- **PRO** para rotina individual intensa
- **Enterprise** para clínica, grupo ou hospital
