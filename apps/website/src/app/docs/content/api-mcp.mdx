## Quando usar

API e MCP fazem sentido quando a sua equipe técnica precisa:

- Integrar a plataforma a sistemas internos
- Criar automações de operação
- Alimentar copilotos e agentes com contexto real
- Expandir o fluxo para além da interface padrão

## O foco

Não é expor dados sem contexto. É conectar a camada técnica da Laudos.AI ao workflow radiológico com governança.

## Casos comuns

- Integração institucional
- Painéis internos
- Rotinas operacionais
- Conectores específicos por hospital ou grupo
